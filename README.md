# Domain testing
Наборы входных данных для проверки программы и ожидаемые результаты.
| Входные стороны (a, b, c) | Ожидаемый результат | Что проверяем |
|---|---|---|
| 3, 4, 5 | Треугольник прямоугольный | Квадрат длинной стороны равен сумме квадратов двух остальных: 5² = 3² + 4² |
| 4, 5, 6 | Треугольник остроугольный | Квадрат длинной стороны меньше суммы квадратов двух остальных |
| 2, 3, 4 | Треугольник тупоугольный | Квадрат длинной стороны больше суммы квадратов двух остальных |
| 1, 2, 3 | Из этих сторон нельзя составить треугольник | Граничный случай: сумма двух коротких сторон равна длинной, а должна быть больше |
| 1, 1, 3 | Из этих сторон нельзя составить треугольник | Сумма двух коротких сторон меньше длинной |
| 0, 2, 2 | Стороны должны быть положительными числами | Ноль недопустим как длина стороны |
| -1, 2, 2 | Стороны должны быть положительными числами | Отрицательная длина недопустима |
